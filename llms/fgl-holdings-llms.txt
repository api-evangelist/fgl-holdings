# F&G Annuities & Life (FGL Holdings)

> F&G Annuities & Life, Inc. is a US life insurance and annuity carrier headquartered in Des Moines,
> Iowa, issuing fixed indexed annuities (FIA), multi-year guaranteed annuities (MYGA), registered
> index-linked annuities (RILA), indexed universal life insurance and pension risk transfer (PRT) group
> annuities. It distributes exclusively through appointed independent agents, Independent Marketing
> Organizations (IMOs), and bank/broker-dealer partners. FGL Holdings is the legacy holding-company name;
> the operating brand is F&G, majority-owned by Fidelity National Financial (FNF).

## Agent note: there is no public API

F&G publishes **no public developer API, no developer portal, and no machine-readable product contract**.
This was established by direct probe on 2026-09-14, not inferred:

- `https://developer.fglife.com` does not resolve (NXDOMAIN). A previous version of this catalog record
  pointed at it; the pointer has been removed.
- `https://api.fglife.com` is a real host (Azure Front Door) but answers
  `{"statusCode": 404, "message": "Resource not found"}` to every public path probed, including
  `/openapi.json`, `/swagger.json`, `/api-docs`, `/graphql`, `/docs` and the full `/.well-known/` named list.
- The corporate sitemap (88 URLs) contains no developer, API, integration or standards section.
- No OpenAPI, AsyncAPI, GraphQL SDL, gRPC/Protobuf, WSDL or OGC contract exists on any F&G host.
- No MCP server, no A2A agent card, no `llms.txt`, no `security.txt`, no `/.well-known/api-catalog`.

Do not attempt to call an F&G business API. Integration with F&G is a **bilateral, appointment-gated
relationship** arranged through an IMO or broker-dealer, not a self-service developer signup.

## What F&G does publish that a machine can read

- [OpenID Connect discovery](https://auth.fglife.com/.well-known/openid-configuration): a complete,
  anonymously-readable OIDC discovery document for F&G's own authorization server (an Auth0 custom
  domain over the `prod.fglife.auth0.com` tenant). Issuer `https://auth.fglife.com/`.
- [OAuth 2.0 authorization server metadata](https://auth.fglife.com/.well-known/oauth-authorization-server): RFC 8414 metadata, same body.
- [JWKS](https://auth.fglife.com/.well-known/jwks.json): public signing key set.

This authorization server gates the **SalesLink** financial-professional portal. It supports
Authorization Code with PKCE (S256), client credentials, refresh tokens, device code, token exchange,
DPoP (ES256), CIBA and back-channel logout. Credentials are issued to appointed distribution partners
only; there is no public client registration.
